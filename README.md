# منصة الإدارة

منصة إدارية داخلية لشركة الاستشارات: الموظفين، العملاء، الطلبات، الشؤون الإدارية، الحسابات، العلاقات العامة.

## اللي شغال لحد دلوقتي
- **الدخول والصلاحيات:** مدير نظام / مدير قسم / موظف، وكل واحد يشوف أقسامه بس
- **العملاء:** العميل (فرد) ← الشركات اللي يملكها (سجل تجاري، رقم موحد، انتهاء السجل)
- **المعاملات:** لكل شركة، بنوع الخدمة والجهة الحكومية والمسؤول والأتعاب والرسوم والموعد
- **سجل متابعة** لكل معاملة: كل تغيير مرحلة أو ملاحظة متسجّل باسم الموظف ووقته
- **لوحة متابعة** بالمراحل + تنبيه للمعاملات المتأخرة والسجلات اللي قربت تنتهي
- **القوائم والمراحل** قابلة للتعديل من الإعدادات (أنواع الخدمات، الجهات الحكومية، مراحل المعاملة)

## التقنيات
- **Next.js** — الواجهة والسيرفر
- **PostgreSQL + Prisma** — قاعدة البيانات
- **Docker + Caddy** — التشغيل على السيرفر مع HTTPS تلقائي

## هيكل المشروع
| المسار | المحتوى |
|---|---|
| `prisma/schema.prisma` | جداول قاعدة البيانات |
| `src/lib/nav.ts` | الأقسام والأقسام الفرعية (القائمة الجانبية) |
| `src/lib/auth.ts` | تسجيل الدخول والصلاحيات |
| `src/app/(dashboard)/` | صفحات المنصة |
| `src/app/login/` | صفحة الدخول |

## التشغيل على السيرفر (أول مرة)
```bash
git clone git@github.com:NGT-C101/admin-dashboard.git
cd admin-dashboard
sudo bash scripts/install.sh
```
السكريبت بيثبّت Docker والجدار الناري، ويولّد كلمات سر قوية، ويشغّل المنصة بـ HTTPS، ويعمل نسخة احتياطية يومية.

## أوامر مفيدة على السيرفر
| الأمر | بيعمل إيه |
|---|---|
| `bash scripts/update.sh` | تحديث المنصة لآخر نسخة (بياخد نسخة احتياطية الأول) |
| `bash scripts/backup.sh` | نسخة احتياطية دلوقتي (في `/root/backups`) |
| `bash scripts/restore.sh <ملف>` | استرجاع نسخة احتياطية |
| `docker compose ps` | حالة الخدمات |
| `docker compose logs -f app` | سجل المنصة (للمشاكل) |
