# نظام التصميم NGT (ds)

الاتجاه: **مؤسسي فاخر وهادئ** على غرار Stripe وLinear وRamp، بهوية NGT (كحلي، ذهب شمباني، أحمر الشعار) وعربية أولاً (RTL).
يُطبَّق تدريجياً صفحةً صفحة. الصفحات التي لم تنتقل بعد تبقى على المكونات القديمة (`.card` وأخواتها) دون تغيير.

## المبادئ
1. **لون واحد لكل وظيفة.** الأحمر `ds-primary` للإجراء الأساسي (زر واحد في الشاشة). الذهب `ds-accent` لما ينتظر قرارك والعنصر النشط والتركيز فقط. ألوان الحالات للحالات فقط.
2. **سطح واحد مرفوع.** `Panel` هو العنصر الوحيد ذو حد وظل. داخلها صفوف بفواصل رفيعة، لا بطاقات داخل بطاقات.
3. **ثلاث درجات للنص:** `ds-text` للمحتوى، `ds-muted` للوصف، `ds-faint` للتسميات الثانوية والأيقونات الساكنة.
4. **الأرقام** بخط العناوين وأرقام متساوية العرض (`tabular-nums`).
5. **RTL أولاً:** خصائص منطقية فقط (`ps/pe`, `ms/me`, `start/end`)، والسهم «للأمام» هو `ArrowLeft`.
6. **حركة قليلة:** انتقالات الألوان فقط (150ms)، ولا حركة تلقائية.

## الرموز (globals.css → @theme)
| الرمز | الاستخدام |
|---|---|
| `ds-canvas` / `ds-surface` / `ds-raised` / `ds-hover` | الخلفية ← اللوحة ← العنصر المرفوع ← المرور بالمؤشر |
| `ds-line` / `ds-line-strong` | الفواصل والحدود / حدود الأزرار الثانوية |
| `ds-text` / `ds-muted` / `ds-faint` | درجات النص الثلاث |
| `ds-accent` / `ds-accent-soft` | الذهب الشمباني وخلفيته الخفيفة |
| `ds-primary` / `ds-primary-hover` | الإجراء الأساسي |
| `ds-success` `ds-warning` `ds-danger` `ds-info` `ds-neutral` | الحالات |
| `font-heading` (Readex Pro) / `font-sans` (IBM Plex Sans Arabic) | العناوين والأرقام / النصوص والجداول |
| `rounded-ds-control` (10) / `rounded-ds-panel` (16) | الأزرار والحقول / اللوحات |
| `shadow-ds-panel` / `shadow-ds-button` | ظل اللوحة / لمعة الزر الأساسي |

**سلّم الخط:** 12 · 13 · 14 · 15 (عناوين اللوحات) · 26 (المؤشرات) · 28–32 (عنوان الصفحة). **المسافات:** 4 كوحدة؛ داخل اللوحات `px-5`، وبين اللوحات `gap-6`.

## المكونات (`@/components/ds`)
| المكون | متى |
|---|---|
| `Panel` + `PanelEmpty` | أي مجموعة محتوى: عنوان، عدد ذهبي اختياري، رابط «عرض الكل» أو وصف قصير |
| `List` + `ListRow` | قوائم داخل لوحة: بداية (نقطة/رقم/أيقونة)، عنوان، وصف، نهاية |
| `StatGroup` + `Stat` | المؤشرات: لوحة واحدة مقسّمة، آخر صف يتمدد |
| `ButtonLink` / `buttonClass()` | primary · secondary · ghost، بحجمين sm/md |
| `Dot` (`Tone`) | نقطة حالة بجانب نص يقولها |
| `Icon` | أيقونات lucide بسُمك 1.75 ثابت وحجم 16/18/20 |

## أول صفحة منقولة
`src/app/(dashboard)/page.tsx` (الرئيسية). عند نقل صفحة: استبدل `.card`/`.card-dark` بـ `Panel`، والمربعات بـ `Stat`، والأزرار بـ `ButtonLink`، ولا تغيّر الاستعلامات أو الصلاحيات.
